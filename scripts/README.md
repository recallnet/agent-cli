# Scripts Directory

This directory contains utility scripts for development, testing, and maintenance of the Recall CLI project.

## Available Scripts

### `test-vector-search.js`

This script tests the vector search functionality with both OpenAI and Anthropic providers to ensure that the embedding service works correctly regardless of which LLM provider is selected by the user.

#### Usage

```bash
# Make sure the project is built
npm run build

# Run the test script
node scripts/test-vector-search.js
```

#### What it tests

The script tests:

1. **Provider Agnosticism**: Verifies that vector search works with both OpenAI and Anthropic providers
2. **Document Storage**: Tests storing a document with embeddings for each provider
3. **Vector Search**: Tests searching for documents using vector similarity
4. **Combined Search**: Tests the combined keyword and vector search functionality

#### How it works

The script creates mock implementations of both the OpenAI and Anthropic embedding providers to generate deterministic mock embeddings. It then:

1. Creates a temporary SQLite database
2. Stores a test document with embeddings generated by each provider
3. Performs vector searches with various queries
4. Tests the combined search functionality
5. Cleans up the temporary database

This ensures that our embedding service works correctly with different providers and can switch between them seamlessly.

## Running Tests

To run the formal test suite, including tests for the embedding functionality:

```bash
npm test
```

The tests for embedding functionality are located in `/tests/embedding.test.ts` and verify that the embedding service works with both OpenAI and Anthropic providers in a more structured way.
